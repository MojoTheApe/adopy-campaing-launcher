# Test History

История тестов: что пробовали, что сработало, что нет.

---

## Таргеты

### EF / FX на Gulf (UAE, KW, BH, OM)
- **Статус:** ✅ Работает
- **Результат:** Стабильные депозиты при высоком CPA. KW — лучший ROI среди Gulf.
- **Вывод:** EF остаётся основным таргетом для Gulf-рынков.

### HV в LATAM (MX, CL, CO)
- **Статус:** ✅ Работает
- **Результат:** Хороший CPL (~$14-20), конверсия зависит от оффера. Лучше всего с Amazon и AI Trader.
- **Вывод:** HV + Amazon/AI Trader = базовый рецепт для LATAM.

### Trading в Центральной Америке (GT, EC)
- **Статус:** ✅ Работает
- **Результат:** GT — один из лучших по ROI при низком спенде. Trading + Video#442 показал хороший CR.
- **Вывод:** Работает в GT и EC, не масштабировать без теста в других странах.

### Wide (Broad) аудитория
- **Статус:** ⚠️ Зависит от страны
- **Результат:** В GT и EC с хорошим пикселем даёт CPL ниже таргетных аудиторий. В Gulf — плохо.
- **Вывод:** Broad работает там, где FB ML достаточно данных. Требует бюджет для обучения.

### Blue Collar
- **Статус:** ❌ Низкое качество лидов
- **Результат:** Высокий объём лидов, но низкая конверсия в депозиты. ROI отрицательный.
- **Вывод:** Не использовать без специального оффера для этой аудитории.

## Офферы

### Amazon + HV + LATAM
- **Статус:** ✅ Проверенная связка
- **Лучшие страны:** MX, CL, CO
- **Вывод:** Массово масштабируемая связка. Стандартный ROI 0.5-1.5.

### Favorita + Trading + Ecuador
- **Статус:** ✅ Работает
- **Результат:** EC показал ROI 36x в лучших кампаниях. Favorita — локальный бренд с доверием.
- **Вывод:** Приоритет для Ecuador. Ограниченный рынок — не масштабировать агрессивно.

### Banco Industrial + FX + Guatemala
- **Статус:** ✅ Работает
- **Результат:** GT = высокий ROI при умеренном спенде. Banco Industrial добавляет доверие.
- **Вывод:** Приоритет для GT. Комбинировать с Video-креативами.

### AI Trader + UAE
- **Статус:** ⚠️ В тесте
- **Результат:** UAE показала ROI 22x в отдельных кампаниях, но нестабильно.
- **Вывод:** Тестировать с осторожностью. Работает при правильном таргете (EF/HV).

### Salik + UAE
- **Статус:** ⚠️ Гео-специфично
- **Результат:** Работает только для UAE. Хорошее знание бренда, но ограниченный рынок.
- **Вывод:** Держать как один из UAE-офферов, не масштабировать за пределы ОАЭ.

## Устройства

### iOS vs All (Android+iOS)
- **Статус:** iOS даёт лучшее качество лидов в Gulf
- **Результат:** В LATAM разница меньше. В Gulf iOS-лиды конвертируются лучше.
- **Вывод:** Для Gulf тестировать iOS-отдельный таргет при ограниченном бюджете.

## Возрастные группы

### 35+ vs 25+
- **Результат:** 35+ даёт лучший CR в большинстве стран. Более зрелая аудитория = больше денег.
- **Вывод:** Начинать с 35+ как дефолт для финансовых офферов.

### 40+
- **Результат:** В Chile и Mexico 40+ иногда лучше, чем 35+. Меньше объём, выше качество.
- **Вывод:** Тестировать 40+ как uplift при достаточном бюджете.
