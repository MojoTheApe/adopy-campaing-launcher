# ACL — Adopy Campaign Manager · runtime dependencies
#
# Pinned with ==, not >=. These are the versions ACL actually runs on today
# (verified 2026-08-25 on the machine that published a live campaign), and ACL
# is installed on many media buyers' computers from this file. With >= each
# machine resolves whatever is newest that day, so a breaking release upstream
# would land on buyers one at a time and look like "RPA broke on my computer".
# Bump deliberately, in a commit, after a run.
#
#   pip install -r requirements.txt
#
# Playwright's own browsers are NOT needed: ACL drives Multilogin's Mimic over
# CDP. Run `playwright install chromium` only if a legacy tool asks for it.
