{# ── Attach-only workflow ── #}
✓ Как запускать RPA (Multilogin)

1. Перед Publish профиль в MLX Desktop лучше не открывать вручную (RPA стартует сам с CDP).
2. Campaign Builder → Preview → Publish (подтверди в модалке).
3. RPA откроет профиль через MLX automation API, зальёт кампанию и не закроет окно — проверь, что Facebook залогинен в нужный аккаунт.

⚠️ Ручной «Quick launch» из MLX Desktop не даёт CDP — RPA не сможет к нему подключиться. Если профиль уже открыт вручную, RPA может перезапустить только его ради CDP (куки сохранятся). После любого исхода окно Multilogin остаётся открытым — не закрываем.

{# ── Paste token directly (no password needed) ── #}
🔑 Вставить automation token напрямую (если нет пароля)

Попроси у владельца воркспейса Multilogin X токен (Settings → Automation → Generate Token) и вставь сюда. Токен сохранится в .env и будет использоваться для запуска профилей.
