## Selected policy and independent ownership

Both `delivery.json.workflow.execution` and `tracker/config.json.execution_policy`
select exactly:

```json
{"schema_version": 3, "implementation_limit": 5, "review_limit": 5, "batch_limit": 5}
```

Schema 3 permits implementation capacity 1..16, source review capacity 1..5 and
batch size 1..5. Schemas 1/2 retain review_limit 1. ACL keeps five Workers,
five source Reviewers, one integration Coordinator and one independent combined
Reviewer as separate limits. Every simultaneous source/integration lane belongs
to a distinct actual Reviewer run; a single run cannot manufacture independence.
A host's real available agent capacity may be smaller than the repository limit.

Each source retains its genuine Worker/branch/claim, singleton PR and current
independent scope/head/base/tree review. Acquire by `execution review-acquire --pr`,
and resume/return/approve using that lane's claim. `record-review` identifies the
same PR/lane/session. `batch approve` releases only that source slot; returned,
stopped or uncertain operations preserve the other owners and their evidence.
The sixth source waits until one of the five slots is released.

Source review and approval may continue while the combined-batch Reviewer holds
the separate integration lane. Approved backlog remains unbounded; only the frozen
batch of at most five reaches stage. Source checks never prove the combined tree.
ACL's CI selector preserves affected checks for one-task sources and full applicable
checks for batch/stage/promotion, manual/release or uncertain policy/routes. The
batch helper preserves exact frozen tips and supports v2/v3; unrelated source
reviews do not block assembly, while an integration review blocks reassembly.

Instruction-only review consumes one source slot and retains it through admitted
main/Merged. Every held process lane blocks new intake/batch creation. Its direct
main admission also waits for stage/intake/integration to be idle, as described in
[PROCESS_INSTRUCTIONS.md](PROCESS_INSTRUCTIONS.md). These rules prevent a process
merge from silently changing an existing frozen baseline.
