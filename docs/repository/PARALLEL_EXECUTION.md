## Normal operation after activation

The current conversation coordinates requested work. Screen dependencies, shared
files and runtime resources; delegate only independent tasks and only as many real
Workers as the host can run and the repository has free slots. Each Worker has
its own branch/worktree, test configuration, ports and data. Platform-neutral
Worker identities are not GitHub Assignee accounts; Coordinator and Reviewer are
separate metadata. Five is a repository ceiling shared across all platforms.

Workers hand off ready PRs, releasing implementation capacity. The Coordinator
reserves the single review/integration lane and invokes a non-implementing
Reviewer. Keep that lane through current-base verification, stage and main merge;
then review the next task. Other Workers may continue development. For any fix or
base reconciliation, return review first and take a fresh author implementation
claim; after stage, retain the lane with `--keep-lane`. Re-review the current
candidate. Package delivery can still be pending after the integration lane clears.
