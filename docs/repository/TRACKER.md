## Ordinary work

1. Read the complete original Issue, requirements and related work. Establish the
   accepted result, dependencies and actual completion before code.
2. Record the actual Worker/session using `python scripts/acl_task_tracker.py work TASK_ID` and verify
   In Progress. Use its isolated task branch; preserve other owners and history.
3. Implement the bounded result and update affected knowledge. Run meaningful
   changed-risk checks, then the required final coverage. Reuse still-valid evidence.
4. Finish the actual handoff: `execution handoff TASK_ID`. Follow the selected ready-PR prerequisite, then immediately record the owned handoff and read it back.
   Keep one genuine `Tracker issues:` line and link the Issue and PR both ways.
5. Obtain a separate non-implementing Reviewer's full-scope assessment of the
   actual head/base/tree, task set and evidence. Record its real report with the
   selected procedure. Author fixes require the owned return/reclaim and fresh review.
6. Source approval uses the genuine review lane and batch approve; keep the source unmerged. The authorized Coordinator freezes a real batch; independently review and check the combined result.
7. Use `check-pr` for early linkage; use `check-merge PR_NUMBER` once for final admission.
   Required independent review and project checks remain prerequisites; use the
   existing project controls. This guide selects no new policy or gate.
8. After actual admitted main integration, finish the accepted delivery, preview
   `merged`, then apply only with `--reviewed-complete` for the genuinely complete
   scope. Keep partial outcomes open; verify the actual task and next snapshot.

## Small changes and evidence

Bounded scope, full accepted-base diff and actual effects determine coverage.
A line count, Markdown extension or label grants no exception. Mixed, incomplete,
executable/build/config/runtime work retains the applicable tests and delivery.
Proven process-only work has its own acceptance; explicit publication remains required.
Keep current independent review and combined review for real batches. A different
agent alone does not invalidate unchanged tests; changed inputs need relevant reassessment.
