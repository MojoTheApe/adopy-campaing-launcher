# Как начать работать с проектом (после открытия Cursor)

## 1. Открыть проект

- Запусти **Cursor**.
- **File → Open Folder** (или **Ctrl+K Ctrl+O**).
- Выбери папку проекта: **`C:\Users\EvgeniSedin\fb_agents`** (или где у тебя лежит fb_agents).
- Дальше работаешь из этой папки.

## 2. Открыть терминал

- В Cursor: **Terminal → New Terminal** (или **Ctrl+`**).
- Убедись, что ты в корне проекта (в пути должно быть `fb_agents`). Если нет:
  ```powershell
  cd C:\Users\EvgeniSedin\fb_agents
  ```

## 3. Что запускать

### Анализ (отчёты по странам, CM, офферы)

```powershell
python run.py
```

Опции: `--excel путь\к\файлу.xlsx`, `--country Ecuador`, `--output output\report.txt` и т.д. Подробнее: `python run.py --help`.

### Агент 5: задачи в Jira из Excel

Файл с аккаунтами: **Upluad FB.xlsx** (путь в `config/paths.py` или переменная `UPLOAD_FB_EXCEL`).

**Создание задач через API** (скрипт сам создаёт задачу и открывает её в браузере):

```powershell
$env:JIRA_EMAIL = "evgeni.s@adopy.com"
$env:JIRA_API_TOKEN = "твой_токен_из_Jira"
python run_jira_from_accounts.py --api
```

Токен один раз создаётся в Jira: https://id.atlassian.com/manage-profile/security/api-tokens  

Переменные `JIRA_EMAIL` и `JIRA_API_TOKEN` нужно задавать в **каждой новой** сессии терминала (или прописать в переменных окружения Windows, тогда не нужно вводить в терминале).

**Только список задач без создания:**

```powershell
python run_jira_from_accounts.py --dry-run
```

## 4. Зависимости

Если при запуске пишет, что не хватает модуля:

```powershell
python -m pip install -r requirements.txt
```

## 5. Где что лежит

| Нужно | Файл/папка |
|-------|------------|
| Анализ (CM, офферы) | `run.py`, `src/analysis_agent/analyze_fb_stats.py` |
| Jira из аккаунтов | `run_jira_from_accounts.py`, `src/jira_agent/jira_from_accounts.py` |
| Пути к Excel | `config/paths.py` |
| Описание агента 5 | `docs/agent5_accounts_jira.md` |
| Git, сохранение | `docs/GIT_ИНСТРУКЦИЯ.md`, `docs/КАК_СОХРАНИТЬ_ПРОГРЕСС.md` |
