# Релизы ACL

Что раздаётся байерам, каким коммитом, и чем доказано, что этот коммит
проверен. Одна строка на релиз, дописывается сверху.

**Правило:** тег ставится ТОЛЬКО на коммит, у которого есть зелёный прогон
сборки, и номер прогона записывается сюда. Иначе «релиз» — это просто чьё-то
мнение о том, что всё работает (замечание **F-14**).

Проверить, что связка не разошлась:

```
python scripts/acl_release_check.py
```

## Как выпускается релиз

1. Отправить изменения, дождаться прогона сборки.
2. Убедиться, что прогон **зелёный** — сборка ставит зависимости с нуля на
   чистой Windows, и только она проверяет, что заведётся новая установка.
3. Перемотать `master` на этот коммит. Ref двигается через `git branch -f`, без
   переключения рабочего дерева: дешборд может работать из этой же папки, и
   подменять код под живым сервером нельзя.
4. Поставить тег и записать сюда коммит и номер прогона.
5. Прогнать `python scripts/acl_release_check.py`.
