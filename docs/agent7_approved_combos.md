# Агент 7: Согласованные связки (Approved combos)

**Цель:** брать **лучшие связки** из вывода агента 1 (Strong/Interesting по странам), дать тебе их согласовать/отобрать, и передать выбранные связки дальше — в п.8 (сбор кампании в Excel под FB) или в таски/Jira.

**Флоу:** связки из агента 1 → твоё согласование → передача выбранных связок в следующие шаги.

---

## Формат связки (из агента 1)

Агент анализа выдаёт комбо с полями:

| Поле | Пример | Описание |
|------|--------|----------|
| Country Final | EC, CO, GT | Страна |
| Offer | Favorita, Banco Industrial | Оффер (из Ad Asset) |
| Device | Mobile, Desktop, ALL | Устройство |
| Interest | Wide, Crypto | Интерес (из адсета) |
| Age | 25-34, ALL | Возраст |
| Creative | CREATIVE, #1 | Креатив |
| TextSegment | TEXT, A | Текстовый сегмент |
| Category | Strong / Interesting | Сильная или интересная связка |
| Deposits, Leads, Spend, Net, CPL, CPA, CR, ROI | числа | Метрики |
| TopAdTitle | строка | Лучший заголовок объявления по депозитам (если есть) |

Связка в одну строку: `{Country} [{Offer}] - {Device} + {Interest} + {Age} + {Creative} + {TextSegment}`.

## Вопросы для уточнения (перед реализацией)

1. **Как ты хочешь «согласовывать» связки?**
   - Вариант A: агент выводит список (в консоль/файл), ты вручную копируешь или помечаешь «эти беру» в файле/таблице — потом скрипт читает этот файл и передаёт дальше.
   - Вариант B: скрипт сохраняет связки в Excel/CSV с колонкой «Approved» (да/нет или галочка), ты ставишь галочки, скрипт читает только отмеченные и формирует выход для п.8.
   - Вариант C: простой интерактив в консоли (показать связку → Y/N или номер).
   - Другой вариант?

2. **Куда именно должны «подаваться» согласованные связки?**
   - На вход агента/шага **п.8** (сбор кампании в Excel под FB) — в каком формате? (тот же набор полей: Country, Offer, Device, Interest, Age, Creative, TextSegment + метрики + TopAdTitle?)
   - Или ещё куда-то: Jira, Make.com, другой файл?

3. **Откуда брать список связок для согласования?**
   - Каждый раз запускать агент 1 и из его вывода отбирать? Или сохранять последний отчёт агента 1 в файл (например `output/combos_report.txt` или `output/combos.csv`) и агент 7 читает оттуда?

4. **Где жить логике агента 7?**
   - В коде (fb_agents): скрипт выгружает связки в CSV/Excel → ты помечаешь approved → скрипт читает и пишет «approved combos» в файл/формат для п.8.
   - В Make.com: сценарий «отчёт/файл → человек помечает → следующий модуль».
   - Связка: агент 1 пишет в файл, агент 7 (скрипт или Make) обрабатывает помеченные и отдаёт в п.8.
