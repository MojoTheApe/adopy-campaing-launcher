## ACL-2782 — Compact status line instead of the OUTDATED box — 2026-11-18

The saved-report marker is now one short line in the header status row ("Saved 12 min ago · waiting for 2 publishes (KLD_BFL_B95, Doc349) and 1 open profile window · updates by itself") instead of the large red box in the bottom-left corner and the red frame around the page. Outdated pages say the short reason, a failed refresh is the same line in red text, and Connections stays as a small link. The names and counts come from the publish queue through the existing `/report/status` poll (no new timers); a stored page from an older build without the header slot gets a small one-line chip at the top.
