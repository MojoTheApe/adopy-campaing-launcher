## ACL-2578 — Readback accepts Meta's image-name suffix; a re-run never reuses a campaign name — 2026-11-12

Readback no longer flags an image whose library name Meta stored with a `_<digits>` suffix (a different image still fails). When a re-run after a stop finds its own left-over campaign (known by id from the name receipt) that cannot be continued because its settings differ, the name is treated as taken even if the Meta listing does not show it: the new campaign becomes "<name> copy N", never a second campaign with the same name. The stop message now names the real copy name instead of "_2". Interacts with ACL-1856 (PR #1569), which changes resume; this fix is on the code in main.
