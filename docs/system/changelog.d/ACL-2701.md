## ACL-2701 — The Graph API backend is the default; RPA only with ACL_FB_BACKEND=rpa — 2026-11-17

Every machine now uses the Graph API backend (reads, campaign commands, warm sessions, Publish, several ad sets)
without any `.env` line. RPA is used only when the machine `.env` says `ACL_FB_BACKEND=rpa` (emergency switch);
an empty, missing or unknown value means `api`. The choice is made in one place, `src/fb_api/backend.py`, used by the
spend reads, publish, commands and the page flag, so the default cannot drift between modules again. Before this,
the installer never wrote `ACL_FB_BACKEND`, so a buyer machine set up by the installer ran on RPA unless the line was
added by hand. Python change: restart the dashboard after the release.
[Task](https://github.com/MojoTheApe/adopy-campaing-launcher/issues/1701).
