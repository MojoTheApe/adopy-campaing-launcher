## ACL-2084 — Square file in the Stories / Reels slot — 2026-11-03

The Stories / Reels file may now be 9:16 or 1:1 (images and videos); the main file stays 1:1 or 4:5.
In the Builder, **Use main file** puts the main file in the slot too: a square file then goes to Feed and
Stories / Reels as one upload under two placement labels. Nothing changes unless the buyer asks for it.
A portrait file, or an ad that can't take two placement rules (several texts, Instant Form, Advantage+,
one placement group), uses the file once with a warning, as before. Changing the main file clears a slot
that still held the old one. Check plan shows the Stories / Reels file of every ad.
