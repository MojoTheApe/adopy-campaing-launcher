## ACL-2258 — Repeat publish of the same campaign — 2026-10-28

Publishing a campaign twice with the same names no longer stops. A creative receipt of the same ad with another content fingerprint is treated as stale instead of an error (unreadable or foreign-account receipts still stop). When Meta answers a creative write with the earlier tagged creative and the only difference is `asset_feed_spec.videos[].video_id`, it is accepted if each differing video pair has the same `length` (read-only GET), with a warning. An interest id that Meta rejects as `Invalid id` in the batch `adinterestvalid` check is dropped from the confirmed cache and the term is searched again instead of failing the plan check.
