## ACL-1856 — Campaign creation keeps durable progress (PR 1: operation journal) — 2026-11-09

The API campaign creator can now record every write in a per-operation journal file on the computer
(`api_operations/<operation id>.json`): "sent" is saved before the request goes to Meta, and the result
(created / unknown / refused / stopped) right after. After a restart the earlier progress is checked in Meta
before the first write; a changed or removed object stops the run with a plain message and nothing is written.
An unknown write result is held for 10 minutes and looked up first, so nothing is created twice.
Unexpected errors no longer lose the IDs of what was already created. Objects stay PAUSED-only.
The journal is opt-in (`CampaignCreator(journal=...)`); wiring it into the publish path and showing it to the
manager come in the next PRs.
