## ACL-1862 — Profile ownership for warm tabs, "Close profiles" and "Open profiles" — 2026-11-01

The per-profile process lease (ACL-1853) now also covers the last warm-profile paths. "Close
profiles" and "Open profiles for today" take the lease without waiting, so they refuse with a
clear message instead of stopping or starting a profile that a read or a job in another ACM
process is using; the lease is held through the whole stop or start. A warm tab is only handed
out to a caller that holds the profile lease, so a cached tab is never permission to act. Nothing
is replayed after a crash (the OS frees the lock), no restart pause is added, and no new Graph or
Multilogin request is made. Refusals leave one `profile_lease_refused` telemetry line.
