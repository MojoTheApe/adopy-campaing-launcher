## ACL-1242 — Core of the Google sign-in (identity label, no UI yet) — 2026-11-04

A manager can be signed in with an @adopy.com Google account (own grant `openid email profile`, token in `token_identity.json`, state in `identity.json`). The verified CM name goes onto Sentry events (`manager`, `identity`, `identity_id`, never the email), problem reports, team-library edits (a lead viewing Bob's dashboard no longer edits as Bob) and the shared action log (which also gets the email). New routes `/api/identity*`; nothing is gated, and the state stays `none` until the sign-in screen ships in the second PR. Neither Sheets token is touched.
