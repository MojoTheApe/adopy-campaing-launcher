## ACL-2583 — A failed read of the journal's campaign no longer counts as "campaign gone" — 2026-11-12

Depends on ACL-1856 (#1569) and ACL-2578 (#1580).

When a publish finds an earlier operation in the journal, it reads that campaign by id. Before, any failed read (timeout, rate limit, Meta 5xx) was taken as "the campaign is gone" and a new operation started, which could create a second campaign next to a live one. Now only Meta's definite "does not exist" answer (code 100 / subcode 33) or a DELETED/ARCHIVED status counts as gone. Any other failure stops the run before any write with "Meta did not answer ... publish again in a few minutes".
