## ACL-2262 — Builder opens the account profile by itself — 2026-10-28

An account worked with in the Builder gets its Multilogin profile opened through the existing warm path
(Add account, Check plan, Publish): a closed profile, or a registered one whose process vanished overnight
or after a restart, is opened or re-adopted before the action. Publish no longer stops with "profile was
closed … Open profiles for today … about 3 minutes"; the button stays as an optional warm-up. A hung
Ads Manager tab (`page_unresponsive`) no longer blocks the action for 10 minutes: the warm path replaces
the tab (the wait is kept when managed sessions are off). The Publish row shows "Opening the profile…".
`ACL_PROFILE_RESTART_COOLDOWN_S` is unchanged.
