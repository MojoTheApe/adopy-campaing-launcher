## ACL-2478 — Offline probe tooling for ACL-2344 step 0 — 2026-11-09

Offline probe tooling for ACL-2344 step 0; no behaviour change; the light work tab itself is not implemented. Adds an offline probe (`src/fb_api/light_probe.py`, `scripts/probe_2344_p1.py`) for running in-page Graph calls from a light same-origin document instead of the full Ads Manager tab. The probe serves the light document from the browser and fails every other request of its own tab (interception pattern `*`, service workers bypassed, interception stays on while the tab lives); a dummy string is handed over through a BroadcastChannel. The probe script is gated to the Doc120 profile (loopback CDP url plus an explicit `--profile-id` equal to Doc120's in the machine's account map). `RawCdp.call` and `PageTab.call` gained an optional `on_event` hook, and `RawCdp` queues messages that nested calls from a handler would otherwise drop; callers that do not pass it behave as before. No publish, read or write code path uses the probe, and the `ACL_LIGHT_WORK_TAB` mode does not exist. The live probe and the implementation stay in ACL-2344.
