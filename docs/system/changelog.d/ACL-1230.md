## ACL-1230 — Support tickets from problem reports via Sentry — 2026-10-23

Owner decision: no own receiver and no GitHub token on buyer machines. Manual problem
reports already reach Sentry with the tag `kind=report`; Sentry's GitHub integration and one
issue alert rule turn each new report into a GitHub issue labelled `support-ticket`.
`docs/system/SENTRY_SUPPORT_TICKETS.md` holds the exact rule and the owner checklist. No
application code changed; the Sentry/GitHub configuration is a separate owner live step and
is not verified yet. Depends on ACL-1273 (one Sentry issue per report): without it only the first report would ever create a ticket.
