## ACL-2244 — Check the remaining call budget at the end of prepare — 2026-11-11

Right before the first write, prepare now checks that the calls left cover every planned campaign, ad set and ad create call plus readbacks. If not, it stops before creating anything and tells the buyer how many calls are missing and that nothing was created. The reservation for targeting reads is unchanged.
