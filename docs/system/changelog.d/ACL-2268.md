## ACL-2268 — Builder: the account profile comes up by itself while you work — 2026-11-07

When you add, duplicate or edit a campaign card in the Builder, the profile of that account is now opened in the background (setting `auto_warm`, **off by default**), so Check plan and Publish find a ready tab. It uses the same path as Publish (`prepare_existing`) in a quiet mode: it never waits, never closes another account's window, never touches a window opened by hand, and is refused while a run is queued, while Meta has paused the account, or when the profile limit or memory is reached. At most one automatic attempt per profile every 30 minutes (kept across restarts); a failed start is never retried. A refusal shows no error: the reason is in the account chip tooltip. The restart pause is unchanged. Needs a dashboard restart.
