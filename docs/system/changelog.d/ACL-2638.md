## ACL-2638 — Header version badge compares with the latest release — 2026-11-28

The header badge of a source build now shows the latest release name when equal, "+N tasks not in release" (tooltip lists ACL ids and titles) when ahead, "release <name> + ACL ids" for test builds with extra task branches, and "release unknown" when the release cannot be read; the `stage` comparison is gone.
