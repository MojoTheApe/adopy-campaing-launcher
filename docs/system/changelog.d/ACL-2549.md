## ACL-2549 — A problem tab and window stay open at the end of a job — 2026-11-12

Part C of ACL-2091. The robot no longer closes the tab that shows a checkpoint, a login page or a Meta block: it only stops driving it (`PageTab.leave_open`), so the buyer can solve it there. This holds on the warm path, the cold read and the cold publish; a frozen tab is still dropped, and a token-only logout (page still on Ads Manager) is not treated as a login page. The warm chip now says "Security check" for a checkpoint instead of "Logged out". A publish job that ends on such a problem keeps the profile window whatever `ACL_KEEP_PROFILES_OPEN` says, holds its slot as a review window and shows the reason line and next step (`profile_problem`) instead of "Nothing was written". A profile closed on purpose by the automatic resume is not kept. `ProfileSlots.resolve_kept` moves a solved review window to idle eviction. Nothing closes a tab with a problem and nothing polls.
