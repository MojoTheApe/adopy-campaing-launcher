## ACL-2465 — Builder: Lifetime start of today that passed in the queue is moved forward — 2026-11-08

The server no longer refuses a Lifetime job whose start of today passed while it waited in the queue (owner's run on Doc280: sent 17:51 with start 18:00, checked at 18:06): such a start moves to the next quarter hour at least 5 minutes ahead. A start on an earlier day is still refused, and Daily is unchanged. Needs a server restart.
