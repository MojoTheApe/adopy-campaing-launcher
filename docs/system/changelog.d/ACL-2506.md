## ACL-2506 — Lifetime form test uses relative dates — 2026-11-10

The Lifetime budget form test in `tests/test_acl1448_israel_time.py` typed the fixed first day 2026-11-10 and failed on that very day, because a start that is already in the past is moved to the current hour (ACL-2462). The test now builds the period from the current Israel-time day (first day = today + 3, last day = first day + 5) and stays green on any date. The "first day is today" behaviour keeps its own test. Test-only change.
