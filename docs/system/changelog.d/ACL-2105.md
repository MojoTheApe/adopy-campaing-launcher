## ACL-2105 — Facebook Pages: fall back to the profile's own Pages — 2026-10-22

When `/{act}/promote_pages` is empty (or does not contain the draft's Page), the robot now also reads the profile's own Pages (`/me/accounts`, only Pages with the ADVERTISE or MANAGE task). Ad-account Pages stay first; every Page keeps its source ("ad account" / "profile"), shown in the Page picker and in the plan summary. A profile Page must pass a read-only usability check (published, promotable) before ads are created; otherwise the run stops before any write with a message naming the Page and the reason. Refresh pages and Instant Forms use the same merged list; telemetry step `api_pages_sources` records the count per source.
