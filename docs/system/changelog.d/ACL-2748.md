## ACL-2748 — An unknown write result no longer stops a publish — 2026-11-17

Owner rule 12.11 (publishing beats blocking). A write with no answer from Meta (`cdp_timeout`, `context_stale`,
`page_closed`, `network`, `network_timeout`) whose two readbacks find nothing is sent again, uploads included
(a duplicate is acceptable, a lost publish is not). If the re-send gets no answer either, only that campaign stops;
the next campaigns of the run still publish. An unclear answer of Meta itself (5xx, code 1/2) is still only reconciled.
[Task](https://github.com/MojoTheApe/adopy-campaing-launcher/issues/1748).
