## ACL-2056 — Instant Form ads: "See details" button — 2026-11-04

Instant Form ads can use the "See details" button (`SEE_DETAILS`). It is the last option, so "Learn more"
stays the default, and it is not offered for website ads. The value is not in Meta's docs (seen on buyer ads),
so it has its own registry rules `acl2056.*`; the documented rules are untouched. Added tests that a form ad
carries the Page's Instagram account (link, video, form created at publish) and that a Page without one is
refused before any write. Several primary texts on a form ad are a separate task.
[Task](https://github.com/MojoTheApe/adopy-campaing-launcher/issues/1056).
