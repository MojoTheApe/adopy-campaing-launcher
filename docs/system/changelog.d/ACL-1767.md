## ACL-1767 — Builder: gender, languages, CTA list, devices, multi-advertiser off — 2026-10-25

Builder 1 on the API path: gender, several languages, devices and minimum OS version, optional ad set start time (in the ad account time zone), a CTA list per destination, and Multi-advertiser ads sent explicitly OFF (`contextual_multi_ads` OPT_OUT, with write policy and readback). Check plan and readback show every new field; empty fields leave the plan of an old draft byte-identical (apart from the explicit multi-advertiser OFF); local draft storage migrates v2 to v3. The default CTA stays Learn more. For an Instant Form the CTA list is exactly the six buttons Meta documents for `link_data` with a lead form (Apply now, Download, Get quote, Learn more, Sign up, Subscribe); Contact us, Get offer, Book now and Request time are no longer offered there. Book now, Order now and Request time are also dropped from the website Leads list: Meta documents them nowhere for website Leads. Minimum OS version must be one Meta lists (static allowlist, refused before any write); "Desktop only" is disabled in the builder (Instagram, Stories and Reels placements need mobile) and Check plan still refuses it. Ad sets and ads follow the ACL-2114 contract (ACTIVE under a PAUSED campaign). RPA-backend behaviour is out of scope (RPA retired for campaigns).
