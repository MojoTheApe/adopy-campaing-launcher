## ACL-2538 — Different ads always get different names — 2026-11-11

Check plan no longer refuses ads whose creative files have no number in their names. The file's own name (without extension, up to 40 characters) now serves as the creative half of the ad name ("coffee beans - Head"); files with a number and ads with a creative id keep exactly the names they had. If two ads in one ad set still get the same name (same file, same text), the later ones become "Name 2", "Name 3" and Check plan shows a note instead of stopping. Stats note: a stem without a number is read by the dashboard as the creative label (via the dash), a stem with a 3-digit number is read as that number.
