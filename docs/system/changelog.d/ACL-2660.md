## ACL-2660 — A Facebook lock is shown on its account only; Open reads the status now — 2026-11-19

A checkpoint or Facebook lock no longer stops the account-refresh queue (local or machine): it is recorded as a hold on that profile and shown on its row only, in red ("Facebook locked", since date, Meta text), never as a green Active from a stale clear. The lock is read from the profile tab URL (`facebook.com/checkpoint`), with no Graph call. A person's Open reads the status immediately and says "Status updated" only when the read time moved. A read stuck in "updating" past the limit ends as failed with Retry. Removing an account drops its machine stop, hold and queue entry.
