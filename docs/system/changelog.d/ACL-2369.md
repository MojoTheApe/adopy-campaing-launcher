## ACL-2369 — Memory limit no longer stops actions on an open profile — 2026-11-09

Account actions (Check plan and the like) on a profile that is already open are no longer stopped by the memory limit: the first action on a warm profile always goes, and the limit applies only to opening a profile or running a second action at the same time. When the limit does stop something, the message says how much memory to free (for example "free about 600 MB more"). The default and the startup-only reading of ACL_MEMORY_MAX_USED_PCT are unchanged. Restart the dashboard after the release.
