## ACL-2321 — Proxy or TLS error at the first navigation is retried once — 2026-10-29

A proxy or TLS network error (ERR_SSL_PROTOCOL_ERROR, ERR_PROXY_CONNECTION_FAILED, ERR_TUNNEL_CONNECTION_FAILED, ERR_TIMED_OUT) at the first navigation of a tab is retried once after about 30 s; the job stays alive for the silence watcher during the pause. If it fails again the job stops with "The profile's proxy did not connect (SSL error). Check the proxy of this profile in Multilogin, then try again. Nothing was sent to Meta." Later navigations and writes are never retried. Telemetry records only the error code and the retry outcome, never the proxy address.
