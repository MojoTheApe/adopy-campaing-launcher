## ACL-1242 — Sign in with the company Google account: screens, setup wizard, docs — 2026-11-06

The dashboard now asks for the @adopy.com sign-in when it opens (state none or expired); "Not now" appears only after a failed sign-in or when sign-in cannot work, and nothing a manager is running is touched. After sign-in ACL confirms the CM name (or asks "Who works here?" if the computer was set up for someone else). The header label "Logged as" is now "Viewing" (it only picks whose accounts to look at) and a chip shows "Signed in as {name}" with the email in its tooltip; an expired sign-in shows a banner. Connections gets Sign in, Sign out and Change name. The setup wizard has a new "Sign in" step between System check and Connections, prefills your name from your Google name, and the Sheets sign-in on the next step opens with your email already chosen. The setup guide and integrations doc describe every new screen.
