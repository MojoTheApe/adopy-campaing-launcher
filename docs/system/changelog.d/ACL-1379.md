## ACL-1379 — Dashboard: turn a campaign off by exact name on tables without ids — 2026-10-25

On accounts whose Ads Manager table has no row ids (Doc19, Doc20, Doc21), the Off button now works for campaigns when `ACL_FB_BACKEND=api`. The robot reads the account's campaign list through the Graph API inside the profile and matches the exact name (whitespace normalised). Exactly one match is turned off by id through the existing ACL-1945 path (`POST status=PAUSED`, read-back confirmation); zero matches, several matches or a partial list are refused and nothing is sent. It is refused while a publish job uses the same profile. The journal entry has `route: api` and `matched_by: name`. Ads cannot be turned off by name (ad names repeat between campaigns), and nothing here can turn a campaign on. The earlier browser-click variant of this task was dropped: RPA is retired for campaigns.
