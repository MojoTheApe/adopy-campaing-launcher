## ACL-2314 — Desktop notification when Check plan or Publish finishes — 2026-10-29

When the dashboard tab is hidden or the window is not focused, the end of Check plan and of a Publish run now sets a badge on the tab title and favicon ("Ready to publish" / "Needs attention") and, if the manager pressed "Notify me when done", shows a Windows notification ("Check finished: N ok, M problems" / "Publish finished: ..."). Clicking it focuses the tab and shows the result. Permission is asked only from that button, never on page load; if it is denied or the API is missing, only the tab badge is used. Optional sound is off by default. The preference is stored per viewer in localStorage. The text carries counts only.
