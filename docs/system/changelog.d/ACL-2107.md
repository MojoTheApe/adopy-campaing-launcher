## ACL-2107 — Batch PRs always run the full CI matrix — 2026-10-22

A combined batch PR (branch `codex/batch-*` or a `Tracker batch:` line in the description) now always
selects the full test matrix (Linux 3.11 and 3.13, all shards, Windows) and never borrows jobs from other
runs of the same tree, so main CI can reuse that run as the provable full run that delivery requires.
Source PRs keep the ACL-1649 scope rule; check names and the release gate are unchanged.
[Task](https://github.com/MojoTheApe/adopy-campaing-launcher/issues/1107).
