## ACL-2344 — Light work tab: offline probe only (P0/P1) — 2026-11-08

Adds an offline probe (`src/fb_api/light_probe.py`, `scripts/probe_2344_p1.py`) for running in-page Graph calls from a light same-origin document instead of the full Ads Manager tab. The probe sends no traffic to Meta: the browser itself serves the light document and a dummy string is handed over through a BroadcastChannel. No publish, read or write code path uses it yet, and the `ACL_LIGHT_WORK_TAB` mode is not implemented. The live probe on a pilot account and the live acceptance are still open.
[Task](https://github.com/MojoTheApe/adopy-campaing-launcher/issues/1344).
