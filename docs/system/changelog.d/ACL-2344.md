## ACL-2344 — Lightweight work page for Graph calls (off by default) — 2026-11-10

Account actions can now run their Graph calls from a lightweight page of the same profile instead of the full Ads Manager app (off by default; `ACL_LIGHT_WORK_TAB=1`), which lowers memory use and avoids page-unresponsive stops on low-memory laptops.
The page is written by the browser itself on the Ads Manager address; every request to that address is answered locally or blocked, so the page itself never reaches Meta, while Graph calls still go through the profile's own proxy. The Graph session is taken once in a normal Ads Manager tab, handed over inside the browser, and that heavy tab is closed. If the page loses the session, a new Ads Manager tab takes it again (one load, counted in telemetry); the page is never reloaded. If the lightweight page cannot be prepared, the account keeps the standard Ads Manager tab. The lightweight page is closed when the dashboard exits, and one left open by a crash is closed on the next tab open of the profile.
