## ACL-2293 — Run limits in Settings, "ceiling reached" — 2026-11-01

Settings (Accounts → Run limits) now changes how many Multilogin profiles run at once (1–8), how many
heavy actions run at once (1–3) and how much memory may be in use before a new profile starts (50–90 %),
without a restart. A change applies to the next start decision; runs that are going are never stopped.
Values are written explicitly to the machine `.env` (Reset to default writes 2 / 1 / 75); more than 3
profiles or above 80 % asks for one confirmation. Queued jobs now say "Waiting: 5 of 5 profiles in use
(ceiling 5)" instead of a bare "waiting for a free slot", and the warm heavy-action limit is no longer
shown as an account wait. The event log gets `run_limits_changed` (numbers only), and slot decisions
carry `ceiling_reached` and `effective_limit`.
