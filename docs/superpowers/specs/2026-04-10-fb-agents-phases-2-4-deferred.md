# Отложенные фазы оркестра fb_agents (2–4)

Документ фиксирует объём работ **после** фазы 1 (аналитика + единый CLI + отчёт v2). Реализация не начата в рамках текущего цикла.

## Фаза 2 — Google Sheet + UploadFB

**Цель:** агент читает последний таб Google Sheet с аккаунтами (`Facebook` + номер + код страны), сверяет с листом **Accounts** в `UploadFB.xlsx`, учитывает колонки **A** (короткий ассет в составе строки), **D** (Asset), **E** (Link).

**Правила Link (уточнить с владельцем):**

| Состояние колонки E | Ожидаемое действие агента |
|---------------------|---------------------------|
| Пусто | Сообщить: открыть таск / нет готового линка |
| URL Jira | Таск открыт — дождаться production-линка |
| Трекинг-линк | Линк готов к обсуждению upload кампаний |

Если строка аккаунта/ассета отсутствует в шаблоне — отдельное правило (аналог «нет такого названия»).

**Технические зависимости:** Google API (OAuth или service account), ID таблицы в конфиге, кэширование чтений.

## Фаза 3 — Сравнение с другими campaign managers

**Цель:** на уровне страны/ассета/адсета понять отставание или перекос относительно других CM (депозиты, CPL, «что скейлить»).

**Зависимость:** единый нормализованный источник строк по всем CM (тот же тип отчёта или общая витрина). Без него агент ограничен только вашими строками.

**Выход:** рекомендации на аккаунт: открыть / бюджет / дубль / выключить; затем сверка с UploadFB и Link.

## Фаза 4 — Креативный агент

**Цель:** чтение [`knowledge_base/`](../../knowledge_base/) + [`knowledge_agent`](../../src/knowledge_agent/knowledge_base.py), диалог (брейнсторм), черновики новых креативов (тексты/angles), без автопубликации в FB на первом шаге.

## Фаза 5 — Локальный дешборд-оркестратор

**Цель:** единая панель (или расширение уже существующего локального UI) для запуска jobs: анализ, upload-bridge, upload-plan, будущие Sheet/креатив.

**Ориентир:** черновик в [`docs/service-architecture.md`](../service-architecture.md) (FastAPI + `/dashboard`), либо Streamlit — выбор при старте реализации.

## Синхронизация с утренней рутиной

После фазы 2: вывод «что сделано» в формате `Account Alias + Country — summary` (например `Facebook111 MX — 2 ad sets AMZ`) при закрытии задачи в Sheet **To Do** / **Done Today** — отдельный триггер (polling или webhook, если появится).
