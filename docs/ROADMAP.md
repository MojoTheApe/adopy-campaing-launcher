## Дальше (по приоритету)

### 1. Путь к Excel вынести из кода
**Задача:** не хранить личный путь к файлу в коде.  
**Как:** читать путь из переменной окружения (например `FB_STATS_EXCEL`) или из простого config-файла; в коде оставить значение по умолчанию только если переменная не задана.  
**Результат:** при pull с GitHub путь у каждого остаётся свой, код общий.

### 2. CLI для скрипта
**Задача:** запускать анализ с параметрами из командной строки.  
**Что добавить (argparse):**
- `--excel` — путь к Excel (переопределяет дефолт/env).
- `--country` — страна для отчёта по офферам (по умолчанию Mexico).
- `--top` — сколько топ-кампаний на оффер выводить (по умолчанию 2).
- `--output` или `--save` — сохранить полный вывод в указанный файл.  
**Результат:** один скрипт, гибкий запуск без правки кода.

### 3. Отчёт по офферам для любой страны
**Задача:** не только Mexico — чтобы можно было запросить Ecuador, Guatemala, Colombia и т.д.  
**Как:** использовать параметр `--country` из CLI (п.2); в `main()` вызывать `print_offer_comparison_and_top_campaigns(df, combos, country_name, top_n)` для выбранной страны.  
**Результат:** одна команда для любой страны, например: `python analyze_fb_stats.py --country Ecuador --top 2`.

### 4. Структура папок (рефакторинг) — сделано
**Задача:** разделить код, конфиг и отчёты.  
**Сделано:** `config/paths.py` — путь к Excel; `src/analysis_agent/analyze_fb_stats.py` — скрипт; `output/` — сгенерированные отчёты; `run.py` — запуск из корня. Документация в `docs/`.

### 5. CI (опционально)
**Задача:** проверять, что скрипт запускается после изменений.  
**Как:** GitHub Actions — установка зависимостей и запуск скрипта с тестовым (малым) Excel.  
**Когда:** когда появится тестовый файл и стабильный формат данных.
